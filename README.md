# AI 감사 실습 데이터 패키지

『AI 에이전트로 바꾸는 내부감사』(윤상혁, 동국대학교 경영정보학과) 부록 E의 실습 파일 패키지다. 본문의 실습에 사용하는 데이터, 문서, 프롬프트, 양식을 세트별 폴더로 제공한다. 세트 이름과 파일명은 본문 각 실습의 '준비물' 항목과 같다.

> **본 패키지의 모든 자료는 실습용 가상 데이터이며 실재 인물, 기관, 거래와 무관하다.** 인명은 김○○ 형태로 비식별하거나 가상 인명을 사용했고, 카드번호는 뒤 네 자리만 남기고 마스킹했으며, 계좌, 연락처, 이메일은 가상 값이다. 각 데이터 파일 끝에는 같은 내용의 고지 행을 두었다.

## 사용 준비

- 도구: 이 책은 ChatGPT와 Claude를 함께 다루며 특정 제품을 전제로 하지 않는다. 문서 검토와 조서 초안처럼 프롬프트 중심 실습은 대화형 도구로, 폴더 단위 정리(KIIA-2)와 HWPX 자동화(KIIA-6)는 폴더를 연동할 수 있는 데스크톱 환경으로 진행하는 편이 맞는다. 파일 업로드, 데이터 분석, 예약 실행 기능은 제품, 요금제, 조직 설정에 따라 다르므로 실습 전에 확인한다. 이 책의 도구와 실습 사례는 2026년 9월 1일을 기준으로 점검했다.
- 각 세트 폴더를 그대로 풀어 두고, 실습에 필요한 파일만 도구에 올리거나 폴더를 연동한다.
- 실제 조직 자료로 바꿀 때에는 개인정보, 계좌, 실명, 기관명을 먼저 마스킹하고, 조직의 AI 사용 지침과 보안 규정을 확인한다. 마스킹이 외부 서비스 입력을 자동으로 허용하는 근거가 되지는 않는다.

## 프롬프트 카탈로그

[prompt-catalog.md](prompt-catalog.md)는 책의 부록 B 전문이다. 58개 코드(PC-01~PC-80, 번호 비연속)를 코드 순서로 싣고, 각 프롬프트의 용도와 본문 위치를 함께 적었다. 회색 박스의 프롬프트는 코드 블록으로 두어 그대로 복사할 수 있고, `{{ }}` 안은 조직과 과제에 맞게 바꿔 넣는다. 본문 실습에 맞게 고친 판본은 '실습 적용형'으로 원문 옆에 함께 실었다.

## 데이터 파일에 심어진 실습 포인트

실습 결과를 대조할 수 있도록 각 데이터에는 확인 대상이 의도적으로 포함되어 있다. 정답 표시가 들어 있는 열이나 시트는 탐지 단계에서 AI에 제공하지 않고, 결과를 만든 뒤에만 대조한다.

- **SMP-3 급여 300행**: 서로 다른 사번이 동일 계좌를 쓰는 사례 2쌍, 초과근무 시간 대비 수당이 과도한 이상치, 기본급 이상치.
- **KIIA-5 경비 300행**: 분할 의심, 승인 누락, 주말 거래, 한도 근접(990,000원대), 중복 의심의 다섯 유형. 「벤포드_분석」 시트는 첫째 자리 9의 실제 비율이 기대치를 초과함을 보여 준다. 두 분석 시트는 결과 대조용이다.
- **KIIA-8 카드 80행**: 비고 열에 확인 대상 8건의 표시. 탐지 단계에서는 비고 열을 제외한 데이터만 제공한다.
- **KIIA-0 카드 444행**: 탐지 규칙 R1~R7(심야, 주말, 검토대상 업종, 분할결제, 중복청구, 고액, 한도 임박)에 걸리는 거래를 포함한다. 규칙과 가중치는 PRD 파일에 있다.
- **KIIA-8 계약서**: 확인 필요 조항 7개에 `[실습포인트]` 주석과 말미 목록표. 정답 비교는 실습을 마친 뒤에 한다.
- **KIIA-4 보조금 15개 시설**: 비고 열에 '집행 저조 확인', '증빙 미비 의심' 표시. 분석에는 비고 열을 쓰지 않는다.
- **KIIA-2 폴더 14종**: 버전 중복(진짜최종 등), 파일명과 내용의 불일치, 스캔본 자리 파일은 분류 실습을 위한 의도된 구성이다. 자세한 설계는 폴더 안 README.txt에 있다.

## 폴더 구성

```
practice-package/
├─ SEM-1_외주용역_계약분할_조서/   7장, 12장
├─ SEM-2_IT보안_인터뷰_조서/       7장
├─ SMP-1 ~ SMP-6/                 6장, 8장, 9장
├─ KIIA-0 ~ KIIA-8/               5장, 6장, 8장, 9장, 11장, 13장
├─ KIIA-공통_지침_스킬/            참고
├─ prompt-catalog.md              부록 B 프롬프트 카탈로그 전문
└─ _build/                        데이터 생성 스크립트(재현용)
```

`_build/` 폴더의 파이썬 스크립트는 데이터와 문서를 생성한 원본이다. 이상 징후를 다시 심어 데이터를 재생성할 때 사용하며, 실습에는 필요하지 않다.

## 주의

- 데이터의 계약 금액, 규정 조항과 이상거래 정답은 학습 효과를 위해 설계한 값이며 실무의 기준값이 아니다.
- 실습에서 도출한 판단을 실제 감사 근거로 옮기지 않는다. 실습 산출물은 초안이며, 감사인이 원문과 계산, 적용 기준을 확인하고 조직의 검토와 승인 절차를 거쳐야 업무 결과로 사용할 수 있다.
- HWPX 파일은 한글(HWP) 2014 이상에서 열 수 있다. AI 도구로 HWPX를 처리하려면 해당 형식을 읽고 쓸 수 있는 환경과 스킬이 필요하다.
