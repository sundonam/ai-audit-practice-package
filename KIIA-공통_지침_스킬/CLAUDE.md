# CLAUDE.md — 감사 업무 폴더 전역 지침

본 자료는 실습용 가상 데이터이며 실재 인물·기관·거래와 무관하다. 이 파일은 감사 폴더에 상주시키는 프로젝트 기준 문서다. 아래 지시는 이 폴더의 모든 작업에 적용한다.

## 1. 기본 원칙
- 모든 작업은 감사조서, 위험 평가표, 개선 권고안 작성에 활용한다.
- 모든 판단은 제공된 파일과 명시된 기준에 근거한다.
- 근거가 부족한 내용은 "확인 필요"로 표시하고 단정하지 않는다.

## 2. 문체 기준
- 간결하고 직접적으로 작성한다. 감정적 표현과 과도한 추정을 금지한다.
- 문장 서술 순서를 고정한다: 사실 → 기준 → 차이 → 영향 → 권고.

## 3. 조서 양식
- 내부감사 결과보고서는 6항목을 유지한다: 감사목적, 관련 규정, 감사결과 요지, 영향 분석, 개선요구 사항, 유의사항.
- 주어는 개인이 아니라 부서·업무 중심으로 쓴다.

## 4. 위험 등급표
- High: 규정 위반이 확인되고 재무·법적 영향이 크거나 반복되는 사안.
- Medium: 통제 미비가 확인되나 영향이 제한적이거나 일회성인 사안.
- Low: 개선이 바람직하나 즉시 위험이 낮은 사안.

## 5. 민감정보 처리
- 개인정보, 계좌번호, 카드번호 전체 자릿수는 결과물에서 제외하거나 마스킹한다.
- 원문에 실명이 있으면 김○○ 형태로 비식별 처리한 뒤 서술한다.

## 6. 영문 파일명 규칙
- 산출물 파일명은 영어 소문자와 밑줄로 통일한다(예: audit_report_2026q1.docx).
- 폴더 연결 루트 경로도 영어로 지정한다.

## 7. 출력 형식
- 표로 제시할 항목은 표로, 서술할 항목은 문단으로 구분한다.
- 근거가 된 파일명과 조·항 번호를 문장 또는 각주에 명기한다.

## 8. 자체 검증 루브릭
- 결과를 내보내기 전 스스로 점검한다: 근거 파일 인용 여부, "확인 필요" 표시 여부, 민감정보 노출 여부, 위험 등급 부여 여부, 6항목 구조 준수 여부.
- 하나라도 미충족이면 산출을 보류하고 사람에게 확인을 요청한다.
