# audit-disposition-writing — 공공기관 처분요구서 작성 스킬

본 자료는 실습용 가상 데이터이며 실재 인물·기관·거래와 무관하다. 이 스킬은 공공기관의 「주의요구·통보」 처분요구서를 공통 초안으로 만들되 실제 기관의 규정과 서식을 우선하도록 설계한다. 처분요구는 공공감사에 관한 법률 제23조 제2항이 정한 법정 조치이므로, 법령·사실·영향·조치가 순서대로 연결되도록 작성 순서를 고정한다.

## 언제 사용하는가
- 감사결과 확인된 사항을 처분요구서 형식으로 정리할 때 사용한다.
- 최종 처분요구 유형과 조치 수준은 권한 있는 사람이 확정하므로, 산출물은 초안으로 다룬다.

## 입력
- 감사결과 확인된 사항(사실 요약), 관계 법령·내부 기준, 관련 기관 의견.

## 5섹션 고정 구조
1. [일련번호]
2. 제목 — [피감행위] 부적정/소홀/미이행 형태의 명사형 지적 구조.
3. 기관명·관계부서
4. 본문
   - 1) 업무개요
   - 2) 관계 법령(판단기준)
   - 3) 감사결과 확인된 사항(관련기관 의견 포함)
5. 조치할 사항 — ① 주의 ② 통보의 이중 구조로 병렬 제시한다.

## 감사결과 핵심 도입 문장(필수)
확인된 사항의 도입은 다음 구조를 따른다.

"그런데 위 관서는 [기대 행위]를 하여야 했음에도 불구하고, [실제 위법·부당 행위]를 [기간 동안] 하고 있었다."

## 문체 5원칙
1. 비난·감정 표현을 배제한다.
2. 기관·지위 중심 주어를 사용한다("위 관서").
3. 종결은 "…되어 있다 / …하지 않고 있었다 / …하여야 했다" 형태로 쓴다.
4. 법령 → 사실 → 결과 → 조치의 논리 순서를 유지한다.
5. 수치·법령 출처를 명기하고, 익명 처리가 필요하면 ☆☆☆☆☆로 대체한다.

## 주의 vs 통보
- 주의: 예방 목적. "앞으로 … 철저히 하시기 바랍니다"로 종결한다.
- 통보: 제도·제재 목적. "…방안을 마련하시기 바랍니다"로 종결한다.
- 한 사안에 ① 주의와 ② 통보를 이중 구조로 병렬 제시한다.

## 4단계 워크플로우
1. 감사사실 구조화 — 기대 행위, 실제 행위, 차이, 기간, 금액을 정리한다.
2. 「확인된 사항」 단독 생성 — 핵심 도입 문장을 포함한 확인 사항 문단을 만든다.
3. 주의·통보 문장 분리 — 예방 문장과 제도·제재 문장을 각각 작성한다.
4. 전체 처분요구서 통합 — 5섹션 구조로 통합한다.

## 주의(중단 조건)
- AI가 생성한 법령·수치는 감사인이 원문으로 검증한다. 검증 전에는 확정하지 않는다.
- 근거 없는 법적 판단, 징계 수위, 책임 귀속을 만들지 않는다.
- 산출물은 초안이며, 최종 처분요구 유형과 조치 수준은 권한 있는 사람이 확정한다.
