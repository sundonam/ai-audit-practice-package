# new-hwpx-master — HWPX 자동 작성 스킬

본 자료는 실습용 가상 데이터이며 실재 인물·기관·거래와 무관하다. 이 스킬은 HWPX 공문·기안문 양식에 내용을 자동으로 채운다. 빈 양식을 첨부하고 채울 내용을 지시하면 폰트와 표 서식을 유지한 채 본문이 들어찬다.

## 언제 사용하는가
- 공공기관 제출용 HWPX 양식의 플레이스홀더를 데이터로 치환할 때 사용한다.
- HWP와 HWPX는 내부 구조가 다르므로, 도구가 지원하는 형식을 먼저 확인한다.

## 입력
- 빈 HWPX 양식 파일, 채울 내용(부서정보·본문·표 데이터).

## 9단계 규칙
1. HWPX 압축 해제 — HWPX는 ZIP 컨테이너이므로 먼저 해제한다.
2. section XML 구조 분석 — sec 직계 자식의 인덱스 맵을 만든다.
3. XML 수정 — linesegarray(줄 배치 캐시)를 반드시 삭제한다.
4. 섹션 본문 교체 — 여러 섹션은 역순(마지막부터)으로 교체한다.
5. 단순 텍스트 교체 — 플레이스홀더를 실제 값으로 치환한다.
6. XML 저장 — 파서로 직렬화하여 저장한다.
7. 재패키징 — mimetype을 비압축으로 첫 항목에 삽입해 다시 압축한다.
8. ZIP 검증 — 재패키징한 파일이 정상 HWPX로 열리는지 확인한다.
9. 공문 작성 원칙 — 경어체·두괄식으로 본문을 정리한다.

## 절대 금지
- 문자열 조합·정규식으로 XML을 직접 조작하지 않는다.
- XML 선언을 수동으로 추가하지 않는다.
- section0.xml 전체를 재작성하지 않는다.
- 텍스트 내용으로 섹션 경계를 탐색하지 않는다.

## 핵심 오류 방지
- linesegarray를 삭제하지 않으면 글자 겹침이 발생한다. 3단계에서 반드시 삭제한다.
- 여러 섹션은 역순으로 교체해 인덱스 밀림을 방지한다.

## 검증(중단 조건)
- 변환 후 표와 글자가 깨지지 않는지 실제 한글 프로그램에서 열어 확인한다.
- 서식이 깨지면 재패키징 단계(7)와 linesegarray 삭제(3)를 다시 점검한다.
